# Requirements

## Supported platform

{: .warning }
> So far, **Ubuntu Linux 24.04 (LTS)** is the only version that has been tested.

| | |
|---|---|
| **OS** | Ubuntu 24.04 LTS — the only version tested so far |
| **AppImage runtime** | Ubuntu **24.04 or newer** |
| **GPU** | Works **with or without** a dedicated GPU — hardware-accelerated 3D when one is present, software rendering otherwise |

On a different OS or Ubuntu version? Consider building with **Docker** — the steps are on the
[Installation]({% link pages/dev/installation.md %}#building-on-another-os-docker) page.
